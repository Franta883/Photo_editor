Frame-by-Frame (Advanced)

For short videos only. Each frame is rendered individually, so the browser must hold every rendered frame in RAM at once.
  • Best for clips under 6 seconds
  • 1080p ≈ 8 MB/frame × 30 fps = ~240 MB/sec of RAM
  • Audio is not included (no real-time sync)
  • Much slower than real-time export
Why use it? Lets you apply expensive per-frame operations (e.g. AI upscale, denoise) to every frame before re-encoding.

Audio

All processing happens via Web Audio. The real-time export uses the processed audio. Frame-by-frame export does not include audio.
